APPLICATION INFORMATION

About Digital Emergency Companion

Learn more about the project and its features.

Project Introduction

Digital Emergency Companion is a web application that brings emergency contacts, medical information, nearby hospital search, first-aid guidance, and emergency history together in one place.

Purpose

The purpose of this project is to help users organize and access essential emergency information when needed.

Key Features

  • Nearby hospital search
  • Emergency contact management
  • Medical information storage
  • First-aid guidance
  • Emergency history
  • Dark mode

Technologies Used

Angular, Node.js, Express.js, and MongoDB.

How to Use

Add trusted emergency contacts, update your medical information, search for nearby hospitals, explore first-aid guidance, and review your emergency history through the sidebar.

Credits

The application uses Angular, Node.js, Express.js, and MongoDB. OpenStreetMap and the Overpass API may provide hospital location data, and Font Awesome provides interface icons.

Important: This application is an emergency-support tool, not a replacement for professional medical advice or emergency services.

ABOUT OUR PROJECT

Digital Emergency Companion

Your digital companion for emergency preparedness, essential medical information, and quick access to emergency resources.

Academic Project

Project Introduction

Digital Emergency Companion is a web application designed to organize important emergency contacts, medical details, first-aid guidance, nearby hospital information, and emergency activity history in one convenient place.

Our Purpose

The purpose of this project is to make essential emergency information easier to access and manage. It helps users keep important details organized so they can refer to them when needed.

WHAT THE APP OFFERS

Key Features

Explore the main features available in the application.

Nearby Hospitals

Search for nearby hospitals using location services when available.

Emergency Contacts

Save, view, call, and manage trusted emergency contacts.

Medical Information

Store and view important medical details in one place.

First-Aid Guide

Access basic first-aid information for common emergencies.

Emergency History

Review recorded emergency activities and available history entries.

Dark Mode

Switch the application's appearance using the dark-mode option.
